# CCS

Blank repository, set up as a place to collect context.

## Layout

```
context/     # drop reference material, notes, docs here
CLAUDE.md    # instructions for Claude Code when working in this repo
```

## Adding context

Put files in `context/`. Subfolders are fine — organise however suits the
material. Anything Claude should always know about the repo (conventions,
commands, domain rules) belongs in `CLAUDE.md` instead, since that is read
automatically at the start of every session.
